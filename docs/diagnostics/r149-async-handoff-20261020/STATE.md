## Последний результат 1281

В минимальном WebGL2-примере ошибка воспроизведена при удалении ещё не завершившей линковку программы, даже без JS-запросов к ней после удаления. Перестановка порядка shader/program не помогла. Native сообщение: `GL_INVALID_VALUE: glGetProgramiv: Program object expected.` Точная внутренняя строка Chromium/ANGLE/драйвера не определена; доказан механизм взаимодействия на уровне API.

В **новой** экспериментальной копии Safe (`r149-minimal-cancel-20261020/three-retire-safe.js`) добавлен LINK_STATUS fence перед native delete неподготовленной программы на живом контексте. Исходный Safe остаётся в `r149-context-boundary-20261020/`. Используется прежнее владение renderer и диагностика shader/link errors; polling и состав программ не менялись.

Три отмены прошли без 1281/native GL warnings; High Start/W, shader/link error path, cleanup и safe context-loss с явным перезапуском по инструкции F5 проверены. Все учтённые ресурсы получили вызовы удаления без дублей. Отсутствие ошибки в трёх попытках **не доказывает отсутствия редкой гонки**.

## Открытые вопросы

1. LINK_STATUS устранил 1281 в трёх проверенных отменах, но синхронная очистка достигала **1,95 с**. Это не случайный таймер; ожидание может блокировать основной поток при отмене. Дополнительная правка не выполнялась.
2. **До последней LINK_STATUS-правки:** новый профиль Safe — медиана **8,888 с**, штатная A — **19,203 с** до управления.
3. Повторный профиль Safe — **4,636 с**, A — **4,128 с**: регрессия **0,508 с**.
4. Преимущество новых профилей подтверждено на ноутбуке, но полная производительность **после LINK_STATUS заново не измерялась**. Correctness-запуски не являются новым A/B.
5. Отзывчивость меню и раннего ввода требует проверки: один поздний presentation меню, вариативность обработки ввода и интервалы кадров сохранены в отчёте диагностической временной серии.
6. Историческая маска движения — **13 318 пикселей, max delta 3/255** — остаётся открытой. Последний fixed Safe совпал с одним исходным Safe; полный знаковый массив отличия к другому исходному Safe повторяет старый A/A. Строгий pixel gate остаётся false.
7. Context loss — безопасное прекращение старого окружения с инструкцией **F5**, а не полноценное восстановление старой игры. Тест использует явный page.reload, автоматического reload нет; старая readiness не возобновляет кадры.
8. **Production-интеграция не разрешена.** Warm-регрессия, позднее меню и FPS в последнем задании не исправлялись.
