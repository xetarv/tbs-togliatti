# Пространственное отсечение растительности — этап 1

Реализовано для поставляемого Three.js r149. Основание: сохранённые `performance-audit.md`, `performance-audit-data.json` и draw census; первичное профилирование не повторялось.

## Область изменения

- Листва и трава подробных деревьев в `visual-assets.js`.
- Ветви и кроны остальных деревьев, кусты и трава клумб в `resources/landscape.js`.
- Растительность центрального квартала и цветы в парках.
- Камыш у дальнего берега: исходные 1500 экземпляров распределяются по ячейкам 32 × 32 метра в локальных координатах группы.

Деревья и клумбы уже пространственно локальны, поэтому их группы не дробятся. Материалы, геометрия, цвета, instance matrices и плотность сохраняются. Скалы, облицовка, статические городские batches и автомобильные группы в этом этапе не меняются.

## Совместимость с r149

Стандартный `InstancedMesh` в r149 имеет `frustumCulled = false`. `Frustum.intersectsObject()` использует сферу базовой геометрии и не учитывает instance matrices.

Новый адаптер `rendering/vegetation-culling.js` регистрирует только выбранные группы в WeakMap. Совместимая обёртка `Frustum.intersectsObject()` использует их отдельные мировые AABB. Все чужие объекты, включая незарегистрированные InstancedMesh, проверяются прежним методом. Только копии наших групп, помеченные в userData и не имеющие собственной регистрации, консервативно пропускаются. Обёртка устанавливается один раз на экземпляр библиотеки. Геометрические буферы, общие boundingSphere и исходный Three.js не изменяются.

Локальный AABB — объединение boundingBox исходной геометрии, преобразованного каждой instance matrix. Для материала с ветром исходная коробка расширяется на ±0,022 по X и ±0,014 по Z **до** instance transform: shader смещает вершины в этих координатах. Так корректно учитываются масштабы экземпляров и родителей. Мировой AABB пересчитывается только при изменении matrixWorld; добавлен запас 0,01 мировой единицы у границ frustum. Проверка в кадре не создаёт временных массивов или геометрий.

Нулевая/невалидная коробка, изменившиеся count, instanceMatrix, геометрия или версия буфера вершин приводят к консервативному пропуску группы. При будущем редактировании instance matrices необходимо установить `instanceMatrix.needsUpdate = true` и вызвать `register()` повторно. После изменения вершин установить `position.needsUpdate = true` и также повторить регистрацию: кеш базовых коробок учитывает ссылку и версию буфера и пересчитывается автоматически. Текущие выбранные группы имеют неизменные instance matrices; ветер анимируется в shader.

## Тени и отражения

Объекты не скрываются через `visible` и не фильтруются только основной камерой. Каждый вызов рендера использует свой frustum, включая WebGLShadowMap. Поэтому группа вне основной камеры остаётся в теневом проходе, если пересекает frustum света. Частично видимая группа сохраняется целиком. Отражающие камеры используют ту же проверку для зарегистрированных объектов, а незарегистрированные копии остаются консервативно видимыми.

## A/B

- `index.html?vegetationCulling=0` — исходные неразбитые группы, отсечение выключено.
- `index.html?vegetationCulling=1` — новая реализация; это также режим по умолчанию.
- Существующий `?play` можно сочетать с параметром через `&`.

Для точного сравнения с прежней реализацией используется отдельный экспорт исходного Git-коммита `aa61f93`, а не только этот параметр. `setEnabled(false)` у адаптера отключает отсечение уже построенных групп, но не объединяет разделённый камыш обратно.

Все 93 подключённых classic scripts ранее разобраны `vm.Script` без синтаксических ошибок; локальные пути существуют, адаптер загружается после реестра TBS и до сборки мира. Контрольные суммы всех 50 артефактов аудита сохранены. HEAD ветки остался `aa61f936887b6986bb319a5bff7a8423d2b47555`; коммит не создавался. `npm run test:browser` также прошёл в Edge: автономный запуск, движение, пауза, камера, освещение, звук, resize, все presets и мобильные кнопки.

`tests/vegetation-culling.test.cjs` использует фактическую локальную библиотеку r149. Проверяются разбиение на границах ячеек и отрицательных координатах, сохранение экземпляров/цветов/флагов, вращения, масштабирование, ветер, общая геометрия, движение родителей, край frustum, независимость камер теней, изменённые буферы, невалидные преобразования и A/B.

Для короткого сравнения подготовлен `node tools/check-vegetation.cjs`: три фиксированных ракурса, одинаковое состояние мира и плотность, сравнение framebuffer SHA-256, счётчики instanced-геометрии основного/теневого проходов и 180 кадров неподвижного рендер-цикла. Результаты сохраняются отдельно в `artifacts/vegetation-culling/`. Путь к отдельному экспорту `aa61f93` передаётся первым аргументом; по умолчанию используется `artifacts/vegetation-culling/baseline-aa61f93`. Перед запуском каждый из 124 файлов baseline сверяется по Git blob SHA. Копия подготовлена через чтение исходных Git-объектов; рабочая ветка и коммит не изменены. В comparison.json сохранены хеши проверенной текущей реализации.

Рабочий Chrome запрещает DevTools remote debugging. Использован отдельный разрешённый тестовый профиль Edge без изменения политик. Финальное аппаратное сравнение выполнено 9 октября 2026 на ANGLE / NVIDIA GeForce RTX 3050 Laptop GPU / Direct3D11, 1024×768, DPR1, high. Оставшиеся риски: совместимость обёртки с другими будущими расширениями Frustum; необходимость обновить границы при новых анимациях/изменении экземпляров; дополнительные draw calls для полностью видимого берега; ложные допуски крупных AABB (без потери видимого содержимого). Реализация и технические проверки завершены; можно переходить к следующему узкому месту, сохранив контрольную проверку RTX 2080 Ti отдельной задачей.
