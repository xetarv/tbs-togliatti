# Проверка кеширования локальных матриц светофоров — 2026-10-12

Эксперимент отклонён: воспроизводимого ускорения на рабочей RTX 3050 Laptop нет.
Исходный рендер восстановлен; TypeScript №3А и прежние оптимизации сохранены.
Baseline: `be5f550909833434289a44951ac2ad277c3c463c`, включающий `8d3bea6`.

Проверено ровно одно изменение в `src/adapters/simulation/traffic.js`: после
создания каждого светофорного head вызвать `updateMatrix()` и отключить
`matrixAutoUpdate` только у head и его непосредственных статичных деталей.
Матрицы мира, материалы ламп, batching, движение транспорта и качество не менялись.
Отклонённый фрагмент перед `scene.add(head)`:

```js
for (const object of [head, ...head.children]) {
  object.updateMatrix();
  object.matrixAutoUpdate = false;
}
```

Использован существующий `tools/check-driving.cjs`, без нового общего аудита:
аппаратный Edge / ANGLE NVIDIA RTX 3050 Laptop / D3D11, file://, 1024×768,
DPR 1, High, seed 72421, полный production step с dt=1/60.
На каждом маршруте 120 кадров прогрева, 600 измеряемых кадров;
порядок A/B/B/A/A/B, три независимых прогона каждого варианта.
Маршруты city-day и waterfront-night прежние, включая поворот и движение
всех 36 машин трафика и 59 пешеходов. Другие тесты одновременно не запускались.
