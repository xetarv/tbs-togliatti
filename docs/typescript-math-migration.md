# Этап №3: миграция math на TypeScript

12 октября 2026. База Git: `8f2ac16e74a0dd593b5cbd2d474b4a0157453441`.
Незакоммиченная инфраструктура этапа №2 сохранена. Переведён только math;
зависимости, графика, физика, управление и игровые правила не менялись.

## Изменения

- `src/domain/math.js` заменён `src/domain/math.ts`, старого исходника в src нет.
- `PointXZ` и `GameMath` перенесены из JSDoc в глобальные интерфейсы
  `types/game-contracts.d.ts`. Параметры, координаты и результаты строго типизированы.
- Регистрация `globalThis.TBS.domain.math = Object.freeze(...)` сохранена.
  Алгоритмы `Math.max(min, Math.min(max, value))` и
  `Math.hypot(a.x - b.x, a.z - b.z)` не изменены.
- Сборка создаёт classic script `dist/domain/math.js`. Нет runtime import/export,
  новых глобальных переменных, any или ts-ignore.
- В index.html изменён только один путь, на прежнем месте:
  `src/domain/math.js` → `dist/domain/math.js`.
- `tsconfig.contracts.json` проверяет math.ts и оставшиеся 10 JSDoc-модулей строго.
- Тестовый helper поддерживает явные пути dist; пять наборов (architecture,
  application, camera, missions, physics) загружают скомпилированный math.
  Ожидания не ослаблялись.
- Единственная правка сборщика — сообщение об обновлении отсутствующего или
  устаревшего JS. Инфраструктура не перенастраивалась.
- README и описание сборки отражают смешанную структуру.
