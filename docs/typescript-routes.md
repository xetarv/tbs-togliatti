# Этап №5: road-network и missions

12 октября 2026. Переведены ровно два исходника: `src/domain/road-network.js`
и `src/domain/missions.js` заменены соответствующими `.ts`. В игре теперь пять
настоящих TS-модулей, не считая технического build-smoke.ts.

Сборщик, зависимости, архитектура и остальные игровые модули не менялись.
Формулы полос, скруглений и парковок, проверки взаимодействия, начисление наград,
зарядка батареи и переключение миссий сохранены.

## Необходимые изменения

- Общие типы ParkingLot, RoadNetworkOptions, RoadNetwork и типы маршрутов/результатов
  миссий перенесены из JSDoc в `types/game-contracts.d.ts`.
  Переиспользованы PointXZ, MissionPoint, MissionDefinition, MissionRules,
  GameState, PlayerState и GameMath. Нет any или подавления ошибок.
- В `tsconfig.contracts.json` заменены два пути. Все 11 контрактов продолжают
  строго проверяться: пять игровых TS и шесть JSDoc-модулей, плюс технический fixture.
- В HTML заменены только два подключения на `dist/domain/road-network.js`
  и `dist/domain/missions.js`, без перестановки скриптов.
- В четырёх существующих наборах тестов (architecture, application, physics,
  missions) обновлены пути. Assertions не ослаблялись; helper не менялся.
- Сгенерированный classic JS получен только через сборку. Старые исходные JS
  отсутствуют в src, регистрации в globalThis.TBS и публичные API сохранены.
- Обновлены README и текущий статус в описании сборки.

## Проверки и сохранённые доказательства

- npm run build → npm run check → npm run build прошли.
  ESLint, Prettier, строгий typecheck, актуальность dist и все 49 тестов успешны.
- 100 адресных сравнений дорожной сети дали одинаковые boolean-результаты:
  полосы и их границы, скругления, городские блоки, парковки и въезды,
  пустые списки дорог и отсутствие парковок. API и заморозка результата совпали.
- 21 сравнение взаимодействия с миссиями подтвердило одинаковые результаты
  и полное состояние: неактивная смена, расстояние и пороги скорости/радиуса,
  получение груза, пауза, доставка всех трёх миссий, 5400 кредитов, зарядка и
  цикл к первой миссии. Идентичность возвращаемых точек сохранена.
- HTML сравнён с архивом: изменены только два пути; новых глобальных переменных нет.
- Браузерная проверка через file:// прошла: ресурсы, запуск, движение, пауза,
