## Как читать результаты

- Сравнивать A/B можно внутри конкретной серии, с её версиями и условиями.
  Ни разницу между соседними отчётами, ни инструментацию нельзя выдавать за A/B.
- Основной стенд — Ryzen 7 7435HS, RTX 3050 Laptop 4 ГБ, 16 ГБ RAM.
  Оконные итоговые серии: Edge 155.0.4283.62, ANGLE/D3D11, High,
  CSS 1528×694, DPR 1,25, framebuffer 1910×867, file://, shader checks=true.
  Раннее исследование запуска было headless 1024×768; его времена выделены отдельно.
- Новый браузерный профиль не означает холодный системный или GPU shader cache.
  Состояние этих кэшей не контролировалось.
- Управление означает реальный Start/W и подтверждённое движение. Отображение
  меню, доставка ввода, возврат render и GPU fence — разные события.
- Вложенные CPU wall intervals не складываются с родительскими; fence не
  измеряет чистую длительность GPU. Ограниченные проверки не исключают все гонки.

## Что сохранено здесь и что осталось локально

Опубликованы компактные итоги, индивидуальные ключевые измерения, ограничения,
происхождение и SHA256 исходных отчётов/выбранных первичных данных. Предыдущая
[документация переноса Safe](../r149-safe-integration.md) остаётся исторической
записью; разрешённая публикация отражена таблицей выше.

Полные ZIP, PNG/RGBA, трассы, браузерные профили, резервные копии и временные
worktree в этот документационный коммит не включены. Они сохранены локально.
Хеш первичного файла позволяет идентифицировать его, но не заменяет сам файл;
данный каталог не является автономным полным пакетом независимой приёмки.

Оригинальная Three.js r149, отдельный Safe vendor, текстуры и игровой код при
этом сохранении не изменялись. Новая оптимизация, FPS-работа или новая серия
приёмки этим документом не назначаются.
