# Кэш геометрии растительности — измерения, память и перенос

Опубликован в `dcedc0238ddb326438acc686a5cdd761e7b9f320`, база `0c74e4e9`.
Это преимущество повторения данных при расширении, а не доказанное крупное
ускорение нынешней сцены.

## Контракт и владение

Приватный Map принадлежит фабрике visualAssets одного мира. Ключ — полный
числовой variant; первые 64 различных варианта сохраняются. После заполнения
новые варианты рассчитываются прежним алгоритмом без вставки и без вытеснения.

Хранятся CPU-шаблоны ветвей и instance-матриц/цветов. Каждый игровой экземпляр
получает независимые изменяемые буферы и прежние собственные геометрии; общие
материалы/геометрии листвы сохраняют исходное владение. Кэш не хранит GPU handles
и не экономит VRAM. При hit воспроизводятся пропущенные 220 Math.random вызовов
UUID r149: порядок RNG, объекты и их итоговые данные сохраняются.

Native-r149 контроль: 76 операций, лимит, отрицательные/большие ключи, повторения,
байты/RNG и независимость буферов проверены. В новой фабрике отдельный пустой кэш.
Данные освобождаются с владельцем; при намеренном удержании старого мира кэш
остаётся достижимым. Терминальный close сам по себе не очищает ещё удерживаемую
фабрику; освобождение владельца — отдельное условие.

## Синтетическое повторение: ещё 126 деревьев

| Метрика                            | A, новый / повторный | B, новый / повторный |
| ---------------------------------- | -------------------: | -------------------: |
| CPU дополнительных 126 деревьев, с |        1,147 / 1,160 |        0,124 / 0,123 |
| До управления, с                   |        8,746 / 4,352 |        7,693 / 3,809 |

Добавочное CPU-время уменьшилось примерно на 89,3%. Это одна пара каждого типа
профиля, не статистическая оценка полного ускорения. Деревья используют те же
варианты и расположены вне игрового района, за culling. Синтетический RNG
изолирован. Мир/дороги/трафик не увеличены: это не четырёхкратный видимый город.
Фактические bufferData-байты первого кадра A/B одинаковы, поэтому такой контроль
не доказывает бесплатность расширения видимых районов или GPU-резидентности.

## Бюджет памяти и lifecycle

36 записей содержат 17 723 520 байт TypedArray backing storage и 831 600 JS-чисел
индексов: ориентировочно 20–24 МБ полезных данных без полного учёта capacity/Map.
На запись — 492 320 байт и 23 100 индексов. При 64 записях — 31 508 480 байт
и 1 478 400 JS-чисел плюс накладные расходы. Лимит на фабрику, не глобально.

Одна адресная проверка настоящей B с WeakRef/CDP и принудительным GC:

Кэш, фабрика, записи и буферы перестали быть достижимы в этом сценарии.
Учтённые geometry/texture counters после терминального закрытия — ноль,
session listeners — ноль. Это не гарантия возврата RSS ОС или отсутствия всех
редких контекстных гонок.

## Long Tasks, изображение, проверки

В прежних B были Long Tasks 54/56 мс после последнего создания растений,
внутри обычного game.step. Непосредственное заполнение кэша в этих интервалах
исключается по меткам; косвенная причина не установлена. Один разрешённый
warm A/B с tracing не воспроизвёл ≥50 мс: max RAF A 32,504 / B 37,331 мс,
max MinorGC A 1,883 / B 2,366 мс. Задержки не объявлены исправленными.

Фиксированный визуальный цикл сохранил состояния мира/камеры/трафика/RNG/воды.
Первый кадр и ночь совпали. Для движения и камеры отличия сопоставлены с целыми
ранее независимо полученными штатными A/A framebuffer и точными знаковыми
масками, а не только с числом пикселей. Новый визуальный дефект не установлен;
универсальная побитовая стабильность всех кадров не обещается.

Единственный дефект комплектации теста исправлен до переноса: эталон из
игнорируемого artifacts скопирован побитово в Git-отслеживаемую
`tests/fixtures/plant-reference-r149.js.txt`, тест читает её. Итог — пять файлов:
TS/сгенерированный JS/контракт/тест/fixture. Перенос совпал с принятой B по SHA256.
Build/check: 113/113, strict TS/ESLint/format/dist parity; 92 classic scripts,
из которых 91 подключён HTML, отдельный build-smoke не добавлен в страницу.
Один Edge High/file:// Start/W, камера и штатная растительность прошли без новых
JS/WebGL-ошибок. Память/A/B при переносе повторно не измерялись.

Принят обмен CPU-работы повторяемых вариантов на ограниченную память владельца.
Новые уникальные варианты после лимита, копирование instance-буферов, обход
сцены и GPU-передача остаются растущими затратами.
