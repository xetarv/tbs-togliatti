- Запечены 10 неизменяемых карт `createQuarterMaterials` существующим PNG-механизмом.
- Точное совпадение исходных/декодированных пикселей, повторной генерации, параметров Texture и контролируемых RNG/состояний подтверждено.

## Состав и проверка

[EVIDENCE_INDEX.json](EVIDENCE_INDEX.json) содержит 143 логических файла: канонические и подготовленные карты, оба bake, манифесты, проверяющие скрипты, полные PNG/RGBA, состояния, знаковые дельты и маски, журналы, patch и полный снимок десяти файлов кандидата в `candidate-source/`.

Одинаковые байты сохранены один раз в двух ZIP. Восстановление возвращает исходные имена и точные байты; изображения не перекодировались. Профили Edge, кэши, node_modules и дублирующие рабочие деревья исключены. Нужные исходники штатной игры доступны в точном базовом Git-коммите. Абсолютные пути в исходных отчётах обозначают происхождение на ноутбуке и не нужны для распаковки.

`SHA256SUMS.txt` проверяет опубликованные файлы, кроме самого списка. `VERIFICATION.json` фиксирует проверку восстановления, всех исходных SHA256 и сохранности прежних рабочих деревьев. Исторические архивы, main, feature и четыре shaderChecks-правки не изменялись.

## Получение на другом ПК

```powershell
git clone --branch archive/quarter-maps-evidence-20261029 https://github.com/xetarv/tbs-togliatti.git tbs-quarter-evidence
cd tbs-quarter-evidence
powershell -NoProfile -ExecutionPolicy Bypass -File .\docs\evidence\quarter-maps-20261029\RESTORE.ps1 -Destination ..\quarter-maps-restored-20261029
```

[RESTORE.ps1](RESTORE.ps1) использует только PowerShell/.NET, проверяет SHA256 ZIP и каждого восстановленного файла, отказывается перезаписывать существующий каталог и не запускает игру или тесты.

Для воспроизведения исходников B нужна отдельная копия базы `166ac744` и точное наложение десяти файлов `candidate-source/` с проверкой по исходному `preservation-after.json`. Не накладывайте их на main автоматически. Прежний `candidate.patch` не содержит новый untracked generator; поэтому полный снимок десяти файлов также включён. npm-зависимости восстанавливаются из штатного lock-файла базы; временные Node-junction ноутбука переносить не нужно.
