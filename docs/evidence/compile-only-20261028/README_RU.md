## Состав и целостность

В [EVIDENCE_INDEX.json](EVIDENCE_INDEX.json) перечислены 496 логических файлов, исходные пути, размеры, SHA256 и точное размещение в шести ZIP. Сохранены оригинальные отчёты, JSON, трассы, PNG/RGBA, состояния, дельты, патчи, проверяющие скрипты и манифесты из 15 исходных каталогов, а также исходный camera ZIP. Повторяющиеся байты хранятся один раз; восстановление возвращает исходную структуру и содержимое без перекодирования.

- [SHA256SUMS.txt](SHA256SUMS.txt): контроль всех опубликованных файлов пакета, кроме самого списка.
- [VERIFICATION.json](VERIFICATION.json): результат выполненного восстановления и проверки происхождения.
- [RESTORE.ps1](RESTORE.ps1): автономное восстановление средствами PowerShell/.NET, без запуска игры, браузера или тестов.

Каталоги профилей браузера, зависимости, кэши, Git-метаданные и повторные рабочие копии A/B не публикуются. Точный список 26 исключённых каталогов приведён в индексе. Код A/B доступен по контрольным Git-коммитам; относящиеся к экспериментам патчи сохранены. Дубликат camera ZIP в Downloads остаётся локально. Другие выбранные первичные доказательства не исключались. Все исходные каталоги и архивы на ноутбуке сохранены.

Оригинальные отчёты скопированы без исправления локальных ссылок. Их относительные ссылки следует читать в восстановленной исходной структуре; абсолютные пути обозначают ноутбук. Новая навигация этого README автономна. Старые утверждения нужно сопоставлять с итоговым статусом выше.

## Получение дома

В существующем клоне, не переключая текущую рабочую копию:

```powershell
git fetch origin archive/compile-only-evidence-20261028
git worktree add --detach ..\tbs-compile-only-evidence-home origin/archive/compile-only-evidence-20261028
cd ..\tbs-compile-only-evidence-home
powershell -NoProfile -ExecutionPolicy Bypass -File .\docs\evidence\compile-only-20261028\RESTORE.ps1 -Destination ..\tbs-compile-only-restored-20261028
```

Путь назначения должен быть новым, несуществующим каталогом. Скрипт сначала проверяет SHA256 ZIP, затем восстанавливает все 496 файлов и сверяет каждый размер и SHA256. Существующие файлы не перезаписываются. После восстановления читайте отчёты и исходные доказательства; автоматическое продолжение экспериментов или merge не разрешены.

Для нового клона можно сначала выполнить `git clone --branch archive/compile-only-evidence-20261028 https://github.com/xetarv/tbs-togliatti.git tbs-evidence`, затем вызвать тот же скрипт из этого клона.
