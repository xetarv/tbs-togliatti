## Визуальный контроль и ограничение

Один цикл A1 → B → A2: RTX 3050 Laptop/D3D11, Edge 156, High/checks=true,
1910×867, DPR 1,25, seed 72421, фиксированный dt. Независимые PNG/RGBA,
состояния и маски сохранены. Затем один дополнительный **только A3** на той же
базе проверил конкретную найденную историческую маску; новых B не было.

В исходном цикле все контролируемые CPU-состояния, мир, транспорт, камера,
RNG и вода совпали. PNG совпали с raw RGBA, GPU errors и отличий после finish нет.
Внешний осмотр сохранённых кадров не выявил пропажи квартала, Fastback, воды,
теней и ночного освещения; он не заменяет строгую проверку пикселей.

`b8d4b251a84bd044f1b52c9a9ca923b0cae6c234ca137c7c98e005ca4b71a7c2`;

`48ddcf14c4cc34fc2befacbb6a7f41b6fb6956a422d114a3310ee004f3d430a0`.

`rng`, `audio`, `futureStates` не совпали, хотя CPU snapshots сцены совпали.
Эти несовпадения не исключены из проверки и не превращены в новый допуск.
