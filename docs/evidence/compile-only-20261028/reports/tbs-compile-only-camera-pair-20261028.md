# Одна причинно-различающая camera-пара — 28 октября 2026

**Camera-кадры B-enabled и B-disabled побитово совпали.**
Влияние дополнительной compile-only-подготовки на изображение в этой паре
не обнаружено. Это не доказывает отсутствие влияния при любых условиях
и не закрывает прежний visual gate относительно A.

## Версии и метод

Оба запуска использовали неизменённую чистую B
`2347940021c074acfd1f5a249c7b3a46ec6895c8`,
ветку `feature/safe-compile-only-startup-20261026`.
Ровно два отдельных новых профиля и запуска: **enabled → disabled**.
Новых A4/A5, третьей попытки, performance A/B и lifecycle-проверок не было.

Оконный Edge **156.0.4314.50**, RTX 3050 Laptop 4096 MiB, NVIDIA **566.07**,
ANGLE/D3D11, r149 Safe, High, shader checks=true, file://.
В обоих кадрах framebuffer 1910×867, CSS 1528×694, DPR 1,25.
Seed 72421; camera получена после 91 фиксированного шага dt=1/60.
Сохранена прежняя последовательность настоящего Start/W, C и CDP mouse drag.

Использована прежняя camera-оснастка из интеграционного checkpoint.
Префиксные first/moving capture выполнены прежним способом, поскольку они
предшествуют camera в существующей методике. Ночной хвост после camera исключён.
Capture читает полный default framebuffer после render, сверяет readPixels
до/после finish и соответствие оригинального canvas PNG полному raw RGBA.
Порогов, маскирования или новых PNG diff-масок нет.

Одна и та же внешняя обёртка в обоих режимах вызывает исходный метод через
`Reflect.apply(originalPrepare, this, args)` и возвращает **тот же Promise**,
без добавочного await/then. В disabled выполнено только:

```js
if (disabled) delete this.__compileOnlyEnvMaps;
```

Постоянные файлы не менялись. Наблюдатель compile одинаков в обоих режимах,
передаёт исходные this/аргументы и снимается после синхронной отправки подготовки.
Его код и происхождение: [feasibility-before.json](feasibility-before.json),
[prepare.cjs](prepare.cjs), [camera-pair.cjs](visual/camera-pair.cjs).

## Ошибки, ограничения и решение

JS/console errors=0; before/read/end WebGL errors=0, PNGChangedBytes=0,
finishChangedBytes=0. Прежние два одинаковых PMREM sigma warnings присутствуют
в обоих запусках. Новых зарегистрированных ошибок нет.

Графические параметры и сохранённое состояние сопоставимы. Динамические GPU
power states и температура, как и состояние системного shader cache, не были
зафиксированы одинаковыми: enabled P8/35°C→P0/39°C,
disabled P0/39°C→P5/41°C. Драйвер/питание не менялись. Это не performance-тест
и не доказательство полной тождественности native среды. Один порядок и одна
пара не исключают естественную вариативность и эффекты очередности/кэшей.

**Вывод ограничен этой парой: различия camera при включении/отключении механизма
не обнаружено. Причина исторических 23 088 пикселей не установлена.**
Отсутствие влияния во всех условиях не доказано; visual BLOCKED относительно A
автоматически не снимается, production/merge не разрешены.

**Одно рекомендуемое решение:** передать эту пару Астре для пересмотра основания
визуального BLOCKED, сохранив B замороженной. Новую серию или исправление renderer
по полученному результату не назначать автоматически.
