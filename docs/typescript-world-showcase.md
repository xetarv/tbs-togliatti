## Контракты и реализация

Переиспользованы `ShowcaseOptions`, `ShowcaseModels`, структуры мира и Three.js r149.
Фабрика сохраняет API `showcaseQuarter(x: number, z: number): void`, регистрацию
через TBS и classic scripts. Существующая сборка создаёт `dist/adapters/world/showcase.js`.
В HTML изменён только этот путь, без перестановки скриптов. Старый JS-исходник удалён.

Новая `types/world-showcase-contracts.d.ts` описывает реальные выходы:

- `QuarterMaterials`: 13 именованных ресурсов — материалы и две текстуры дороги.
  Переиспользованы категории material/standard/physical/basic и texture.
- `QuarterStructure`: изменяемый массив панелей с x/y/z/w/h/side и функция
  `wall(px, py, pz, w, h, d, material?)`, возвращающая результат существующего `BoxHelper`.
- `QuarterRoof`: `roofGlass`, реальный клон физического материала glazing.
- `QuarterInitialContext`, `QuarterStructureContext`, `QuarterRoofContext`:
  последовательные стадии одного объекта, без фиктивного универсального ресурса.
- Именованные входные проекции всех десяти функций, сверенные с фактическими
  деструктурируемыми параметрами внутренних JS-реализаций.

В `WorldResources` уточнён изменяемый `nightWindows`: фабрика материалов действительно
выполняет `push(warm)`. Readonly-представление для существующей презентации сохранено.

Исходный context создаётся тем же spread. Сохранены `Object.assign` после структуры
и крыши. TypeScript не расширяет тип переменной после этих мутаций, поэтому
использованы локальные сужения только при чтении wall, roofGlass и claddingPanels.
Предпосылки сужений проверены по JS-возвратам и адресными тестами. Runtime-веток,
копий контекста, дополнительных вызовов или аллокаций типизация не добавляет.

Внутренние JS-строители квартала не изменены и не объявляются статически проверенными.
Строгая типизация покрывает TS-адаптер, его потребителя bootstrap и объявленные границы.

## Эквивалентность

Исполняемый AST исходника и скомпилированного JS совпал полностью после исключения
метаданных оформления. Четыре коротких сценария сравнили прямые вызовы и настоящий
скомпилированный `bootstrap/world.js` с контролируемыми фабриками; каждый сценарий
вызвал квартал дважды. Дополнительно проверены конфликтующие поля options,
getter-свойства spread и Object.assign, symbol-свойства, порядок ключей и мутации.

Подтверждены исходный API, возвращаемое undefined, отсутствие создания материалов
до вызова showcaseQuarter, создание нового контекста при следующем вызове,
одна ссылка context у всех девяти строителей и идентичность переданных ресурсов.
Последовательность сохранена:
materials → ground → structure → windows → roof → pavilion → branding → landscape
→ lighting → cladding.
