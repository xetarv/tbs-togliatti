## Сохранение предыдущих исходников

Шесть монолитных скриптов предыдущей опубликованной версии сохранены без изменения
содержимого в `docs/legacy-source/*.js.txt`: `ambient3d`, `embedded-assets`,
`game3d`, `graphics3d`, `hero-car`, `visual-assets`. Эти файлы не исполняются.
Актуальный `index.html` загружает исходники из `src/` и ресурсы из `assets/`;
устройство уже выполненного рефакторинга описано в `refactoring.md`.

Добавлен `.gitattributes`: LF для текстовых файлов соответствует EditorConfig и
не позволяет Windows autocrlf нарушить проверки в новом clone. Архивные исходники
сохраняют точные blobs предыдущего коммита.

## Продолжение разработки дома

Предпочтителен новый clone, чтобы сохранить незакоммиченные домашние изменения:

```sh
git clone https://github.com/xetarv/tbs-togliatti.git tbs-togliatti-laptop
cd tbs-togliatti-laptop
npm ci
npm run check
```

Нужен Node.js 24 или новее. Ожидаются 45 тестов. Для игры достаточно открыть
`index.html`; зависимости нужны для проверок и разработки.

`artifacts/` исключён из Git. Для воспроизводимого A/B необходимо отдельно перенести
локальный архив диагностических материалов и распаковать его в корень clone,
восстановив `artifacts/`. Точный состав архива, SHA-256 и исключённые файлы приведены
в локальном manifest рядом с архивом. Архив не публикуется на GitHub. Raw heap
snapshots и существующие zip не включаются: исходные файлы остаются на ноутбуке.
