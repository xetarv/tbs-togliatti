# Этап №4: config и collision

12 октября 2026. На существующей инфраструктуре переведены только два игровых
модуля: `src/domain/config.js` → `config.ts` и `collision.js` → `collision.ts`.
Оба небольшие, не требуют новых зависимостей или изменений других игровых модулей.
В игре теперь три настоящих TS-модуля: math, config, collision. Технический
build-smoke.ts в это число не входит.

## Изменения

- Сохранены численные константы, строки миссий, структура конфигурации,
  рекурсивная заморозка, isParkBlock и алгоритм SAT столкновений.
- JSDoc-типы перенесены в глобальные интерфейсы и VehicleContactTest
  в `types/game-contracts.d.ts`. Регистрация через globalThis.TBS сохранена.
- Приватный freeze остаётся generic; элементы Object.values рассматриваются как
  unknown, без any и подавления ошибок. Это не меняет runtime-код.
- Генерация идёт в `dist/domain/config.js` и `dist/domain/collision.js`.
  Результаты не редактировались вручную.
- В HTML заменены только два пути, на прежних местах. Старые исходники удалены
  из src; их копии сохранены в диагностическом архиве.
- В tsconfig.contracts.json обновлены два пути; строго проверяются три игровых TS
  и оставшиеся восемь JSDoc-модулей, плюс технический fixture.
- В пяти тестовых наборах (architecture, application, missions, physics, traffic)
  заменены соответствующие пути на dist. Assertions и ожидаемое поведение сохранены.
- Обновлены README и текущий статус в описании сборки. Сборщик не менялся.

## Подтверждённые результаты

- После config: сборка успешна, 17/17 связанных тестов.
- После collision: сборка успешна, 7/7 связанных тестов.
- Config: рекурсивное сравнение значений, структуры, порядка ключей, заморозки
  и дескрипторов совпало; 143 проверки isParkBlock совпали.
- Collision: 400 адресных сравнений контактов при пяти направлениях, зазорах,
  касании, пересечении и перестановке автомобилей совпали. 274 контакта и
  126 результатов null; координаты и глубина совпали через Object.is,
  включая знаковый ноль. Заморозка API, имя и арность функции сохранены.
- Сравнение HTML с архивом подтвердило только замену двух путей;
  новые глобальные переменные не появились.
- Итоговый npm run build → npm run check → npm run build прошёл.
  ESLint, Prettier, строгий typecheck, актуальность dist и 49/49 тестов успешны.
- Браузерная проверка через file:// прошла: ресурсы, запуск, движение, пауза,
  камера, освещение, звук, resize, все графические пресеты и сенсорное управление.

Артефакты: `artifacts/typescript-domain-pair-29ec6892/`. Сохранены оригиналы двух
модулей и HTML, verify-pair.cjs, comparison.json, логи отдельных сборок и тестов,
final-check.log, build-after-check.log, browser.log и предыдущие браузерные снимки.
